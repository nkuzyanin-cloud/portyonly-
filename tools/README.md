# Редактура исходной базы

`revise-recipes-1.2.py` — инструмент однократной редакторской миграции базы 1.2 в редакцию 2. Он не используется приложением. Для воспроизведения нужен исходный `data/recipes.json` версии 1.2:

```
python3 tools/revise-recipes-1.2.py --input /path/to/1.2/recipes.json --output /path/to/result/recipes.json
```

Скрипт выдаёт статическую базу и `recipe-audit.json`, проверяя использование всех ингредиентов. Не запускайте его на уже исправленной базе 1.3: это не повторная миграция. Для обычной работы Portionly Python и сборка не нужны.
