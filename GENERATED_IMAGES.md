# Изображения Portionly

Все 400 изображений созданы отдельно встроенной генерацией изображений OpenAI по названию, ингредиентам и технологии конкретного рецепта. Сторонние фотографии в этой версии не используются. Изображения иллюстративные; внешний вид приготовленного дома блюда может отличаться.

Общий стиль: тёплый светлый фон, мягкий дневной свет, спокойная посуда и минимум предметов. Итоговые файлы — локальные WebP до 800 px. Соответствия, даты и контрольные суммы: IMAGE_LICENSES.json. Точные запросы: GENERATION_PROMPTS.json.

Файлы поставлены пятью частями: 99 + 99 + 99 + 99 + 4. Первые четыре ZIP содержат только изображения. Пятый содержит оставшиеся четыре изображения и весь код приложения, базу блюд, иконки, PWA-файлы и сведения об изображениях. Пять архивов вместе содержат полный готовый проект; прежний архив не требуется. При загрузке через интерфейс GitHub добавляйте содержимое каждого архива, сохраняя папки и имена: assets/photos/…, data/recipes.json, app.js и sw.js в корне.

После загрузки всех пяти частей откройте приложение онлайн, дождитесь установки обновления, затем закройте и откройте его. Пользовательские данные IndexedDB сохраняются. Просмотренные новые изображения кэшируются; все сразу можно сохранить в настройках кнопкой «Скачать все фотографии».
