# Portionly

Готовая семейная PWA без сервера, регистрации и сборки.

1. Загрузите **содержимое ZIP** в корень GitHub-репозитория: рядом должны оказаться `index.html`, `app.js`, `data/` и `assets/`.
2. GitHub → Settings → Pages → Deploy from a branch → main → / (root) → Save.
3. Откройте опубликованную HTTPS-ссылку. На iPhone: Safari → Поделиться → На экран Домой.

Локальная проверка: `python3 -m http.server 8080`, затем http://localhost:8080. Открытие двойным нажатием на HTML не поддерживает PWA.

Первое открытие сохраняет приложение и все рецепты для офлайн-работы. Фото загружаются по мере просмотра; в настройках можно скачать их все. Для резервной копии: Настройки → Экспорт JSON. Импорт заменяет текущие пользовательские данные после подтверждения.

Данные устройства не синхронизируются с другими телефонами. Удаление данных сайта или PWA может удалить локальные данные — сохраняйте JSON. КБЖУ ориентировочно; дата расхода готовой еды не является сроком безопасного хранения.

Источники рецептов: `SOURCES.md`. Источники и лицензии фото: `IMAGE_LICENSES.json`. Лицензия адаптированной базы: CC BY-SA 4.0. Код: MIT (`LICENSE`).

При обновлении загрузите новые файлы и измените VERSION в `sw.js`. После успешной загрузки новой версии закройте и откройте приложение; IndexedDB сохранит вашу кухню.
